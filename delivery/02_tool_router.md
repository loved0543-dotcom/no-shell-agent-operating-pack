# 02 Tool Router

## 쉬운 선택 기준
- 글, 문서, 요약, 답장 초안: ChatGPT / Claude / Gemini.
- 코드 수정, 로컬 파일, 앱 제작, 자동화 스크립트: Codex.
- 로컬 PC 전체 운영, 반복 학습, 여러 작업 연결: Hermes.
- 앱끼리 연결: Zapier / n8n.
- 이메일/문서 계정 읽기와 초안 생성: Gmail / Drive / Docs / Notion 커넥터.
- 브라우저 로그인 상태가 필요한 반복 작업: Chrome 자동화 + 허용 URL/대상/실행범위.
- 디자인/썸네일/프레젠테이션: Canva / Presentations / Imagegen.
- 표, 계산, 데이터 정리: Spreadsheets / Google Sheets.

## 플러그인/스킬 선택 문장
```text
이 업무를 자동화하려면 어떤 도구가 필요한지 먼저 골라라. 
내가 모르는 도구 이름을 쓰면, 그 도구가 무엇인지 한 문장으로 설명하고 왜 필요한지 말해라.
도구 없이 자연어와 파일만으로 가능한 부분, 플러그인이 필요한 부분, 권한형 계정 연결이 필요한 부분, 정확한 라이브 실행 지시가 필요한 부분을 나눠라.
```

## 선택 금지
- 처음부터 5개 이상 도구를 묶지 않는다.
- 계정/결제/비밀키가 필요한 작업을 우회 실행하지 않는다.
- OAuth/플러그인/로그인 세션 없이 메일함, 쿠키, 토큰, 복구코드, 비밀번호를 요구하지 않는다.
- 라이브 발송/게시/결제/계정변경은 허용 대상과 정확한 실행 지시 없이 실행하지 않는다.
- 실패 원인을 모른 채 새 플러그인을 더 깔지 않는다.
