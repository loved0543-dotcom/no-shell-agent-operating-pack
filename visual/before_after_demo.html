Before / After: 같은 “자동화” 요청, 완전히 다른 결과

차이는 도구가 아니라 업무를 맡기는 구조다. 입력, 출력, 사람 경계, 테스트, 실패복구가 없으면 AI 자동화는 껍데기로 끝난다.

BEFORE — 흔한 지시
내 이메일 답장 자동화 만들어줘.
입력 이메일 유형이 없다.
답장 초안인지 실제 발송인지 모른다.
Gmail/Docs/Sheets 중 결과 위치가 없다.
사람 확인 경계와 테스트 입력이 없다.
실패하면 무엇을 고칠지 없다.
판정: 껍데기 위험 높음
AFTER — 운영팩 지시
내 고객 이메일 처리 업무를 자동화 가능한 하나의 흐름으로 좁혀라.
입력, 반복주기, 판단 기준, 결과물, 저장 위치, 사람이 확인할 경계, 실패하면 큰 문제인 부분을 표로 채워라.
정상/정보부족/민감 요청 테스트 입력 3개와 예상 결과를 보여라.
입력: 고객 문의 이메일
출력: 분류 + 답장 초안
저장: Gmail Draft 또는 Docs
사람 경계: 발송 전, 환불/불만/민감정보
실패복구: 판단 기준/출력 형식/도구 연결 수정
판정: 첫 테스트 가능
