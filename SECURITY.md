# Security Policy

## Supported scope

This repository contains operating documents, rendered artifacts, and validation scripts for AI automation workflows.

## Do not submit

- API keys
- access tokens
- cookies
- private customer data or records
- private chat transcripts
- screenshots containing secrets
- credentials for OpenAI, GitHub, Google, Notion, email, commerce, or payment accounts

## Reporting a vulnerability

Open a GitHub issue with:

- affected file
- risk description
- reproduction steps if applicable
- recommended fix

If the issue involves a private secret, do not paste the secret. Describe the file path and the kind of exposure instead.
